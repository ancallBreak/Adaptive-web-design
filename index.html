Наши возможности

Адаптивность

Страница корректно отображается на телефонах, планшетах и ПК.

Flexbox

Используется для расположения элементов в шапке и в меню.

CSS Grid

Карточки автомотически перестраиваются юлагодаря auto-fit и minmax.

Брейкпоинты

768px и 480px - типовые точки перелома для моб. устройств.

Viewport

Видимая пользователю область веб-страницы на экране устройства, исключая элементы интерфейса браузера.
